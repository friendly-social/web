# User validation

> Author: @y9san9
> Tags: Good first issue

Currently user validation either on sign up or in edit only tells about errors
when you click the button to proceed. It is bad user experience, because I had
reports of people spending an hour to fill their profile and then getting "Oh,
max length is 1024 chars".

There is also no counter that shows how much you need to cut. I even stumbled on
this myself, but my case primarily was due to long links I used for images.
